# הסנפשוט — מה שהופך ריצה בודדת לכלי

בלי סנפשוט, SWOT הוא מסמך שנכתב פעם אחת ונשכח. עם סנפשוט, כל ריצה חוזרת
עונה על השאלה **"מה זז?"** — וזו השאלה השווה היחידה.

---

## הקובץ

`outputs/snapshots/YYYY-MM-DD.json` (או `snapshots/` בלי מבנה משרד דיגיטלי).
**קובץ אחד לריצה. לא דורסים סנפשוט קיים.**

```json
{
  "date": "2026-09-27",
  "business": "סטודיו אלומה",
  "coverage": {
    "competitors": 4,
    "sitesRead": 4,
    "socialScanned": false,
    "socialReason": "אין APIFY_TOKEN",
    "skippedQuestions": ["תלויות בספק"]
  },
  "competitors": [
    { "name": "...", "site": "...", "readAt": "2026-09-27" }
  ],
  "quadrants": {
    "S": [{ "id": "S1", "text": "...", "source": "ראיון", "url": null,
            "kind": "fact", "strength": 3 }],
    "W": [], "O": [], "T": []
  },
  "moves": [
    { "id": "M1", "type": "SxO", "action": "...", "basis": ["S1", "O3"],
      "impact": 3, "speed": "fast", "done": false }
  ]
}
```

**מזהים יציבים.** פריט שנשאר מריצה לריצה שומר את ה-`id` שלו. פריט חדש מקבל
מזהה חדש. בלי זה אין השוואה — יש שתי רשימות לא קשורות.

---

## ההשוואה בריצה חוזרת

1. קרא את הסנפשוט **האחרון לפי תאריך** (לא את כולם).
2. הצג למשתמש מה היה, לפני שאתה שואל משהו:

```
הסנפשוט האחרון: 27.9.2026 (לפני 94 יום)
  4 חוזקות · 3 חולשות · 5 הזדמנויות · 3 איומים
  3 מהלכים סומנו בוצעו

נעבור על מה שהשתנה. לא נחזור על כל הראיון.
```

3. התאמת פריטים — לפי `id` אם המשתמש אישר שהפריט עוד תקף, ולפי טקסט דומה
   אם לא בטוח. **במקרה גבול שאל.** התאמה שגויה מייצרת "נעלם" ו"נוסף" מדומים,
   וזה גרוע מלא להשוות בכלל.

---

## הכתיבה ל-`swot-settings.md`

אחרי כל ריצה, עדכן שם:

```md
## היסטוריה
- סנפשוט אחרון: `outputs/snapshots/2026-09-27.json`
- ריצות: 27.9.2026, 12.7.2026
- שאלות שדולגו: תלויות בספק
```

---

## המהלכים שסומנו בוצעו

זה הלב. בכל ריצה חוזרת, לכל מהלך עם `done: true` בסנפשוט הקודם, בדוק מה קרה
לשני הפריטים שהוא נגזר מהם (`basis`):

| מה קרה לפריטים | מה אומרים |
|---|---|
| החולשה נעלמה או נחלשה | *"המהלך עבד — החולשה X ירדה מ-3 ל-1."* |
| הפריטים לא זזו | *"המהלך סומן בוצע, אבל X ו-Y לא זזו. שווה לבדוק אם הוא באמת בוצע, או שהוא לא היה המהלך הנכון."* |
| נעשה גרוע יותר | נאמר כמו שהוא, בלי לרכך |

**אל תניח שמהלך שסומן בוצע עבד.** הסימון הוא מה שהמשתמש דיווח; הפריטים הם
מה שקרה. כשהם לא מסתדרים — **הפער עצמו הוא הממצא**, וזה בדיוק מה שאף מסמך
SWOT רגיל לא נותן.
