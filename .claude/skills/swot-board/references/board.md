**קובץ אחד עצמאי.** עברית, RTL, נפתח בדאבל-קליק בכל דפדפן, עובד בלי אינטרנט.
בלי CDN, בלי פונט חיצוני, בלי ספרייה. הכול inline.

## איך בונים — התבנית

**לא כותבים את הקובץ מאפס.** `references/board-template.html` הוא לוח שלם
(עיצוב, משבצות, טבלת מהלכים, לשונית "מה זז", פאנל, localStorage, הדפסה).
הבנייה היא שני צעדים:

1. מעתיקים את התבנית ל-`outputs/SWOT.html`.
2. מחליפים את המחרוזת `/*DATA*/{}/*/DATA*/` ב-`/*DATA*/<JSON>/*/DATA*/`, כשה-JSON
   הוא אובייקט ה-`DATA` שמתואר למטה (זהה למבנה הסנפשוט + שדה `previous`).

```bash
python3 - <<'PY'
import json
tpl = open('.claude/skills/swot-board/references/board-template.html').read()
data = json.load(open('outputs/snapshots/2026-09-27.json'))
data['previous'] = None            # או: json.load(open('outputs/snapshots/<הקודם>.json'))
open('outputs/SWOT.html','w').write(tpl.replace('/*DATA*/{}/*/DATA*/', '/*DATA*/'+json.dumps(data, ensure_ascii=False)+'/*/DATA*/'))
PY
```

לשנות את התבנית עצמה — רק אם המשתמש ביקש שינוי עיצובי. הנתונים לא נערכים ב-HTML.

## מקור האמת

הנתונים מוזרקים לאובייקט `DATA` בראש ה-`<script>`:

```js
const DATA = {
  business: "סטודיו אלומה",
  date: "2026-09-27",
  coverage: {
    competitors: 4,
    sitesRead: 4,
    socialScanned: false,
    socialReason: "אין APIFY_TOKEN",
    skippedQuestions: ["תלויות בספק"]
  },
  quadrants: {
    S: [{ text: "...", source: "ראיון", url: null, kind: "fact", strength: 3 }],
    W: [...], O: [...], T: [...]
  },
  moves: [{
    type: "SxO",              // SxO | WxO | SxT | WxT
    action: "...",            // משפט פעולה אחד
    basis: ["S1", "O3"],      // מזהי הפריטים שממנם נגזר
    impact: 3,                // 1-3
    speed: "fast",            // fast | medium | heavy
    done: false
  }],
  previous: null              // הסנפשוט הקודם, אם יש — למסך "מה זז"
};
```

> ⚠️ **`DATA` הוא הפלט, לא המקור.** מקור האמת הם `swot-settings.md` והסנפשוט.
> בנייה מחדש דורסת את ה-HTML — לא עורכים אותו ביד.
> היוצא מן הכלל: `done` על מהלך, שנשמר ב-localStorage (ראה למטה).

## המסכים

### 1. ראש הלוח

- שם העסק + תאריך.
- **שורת הכיסוי, ראשונה, לא מוסתרת:** כמה מתחרים, כמה אתרים, והאם הרשתות נסרקו.
  לא נסרקו → נכתב במלל: *"הרשתות של המתחרים לא נסרקו — הניתוח מבוסס על אתרים
  ותוכן ציבורי."* שאלות שדולגו נכתבות שם גם.
- מונה: `4 חוזקות · 3 חולשות · 5 הזדמנויות · 3 איומים · 11 מקורות`.

### 2. ארבע המשבצות

גריד 2×2 בדסקטופ, טור אחד בטלפון. כל משבצת בכרטיס עם כותרת וצבע משלה.

כל פריט = שורה עם:
- הטקסט
- **חיווי עוצמה** — שלוש נקודות, מלאות לפי `strength`
- **תג מקור** — `קונטקסט` / `ראיון` / דומיין. יש `url` → התג הוא קישור שנפתח בטאב חדש
- `kind: "impression"` → הטקסט בנטוי ולפניו `נראה ש-`

**`❔` ליד כותרת כל משבצת**, טולטיפ CSS בלבד, שמסביר בשורה מה נכנס לשם ומה לא —
במיוחד ההבדל בין חולשה (בשליטתך) לאיום (בחוץ). הטולטיפים מוזרקים לאלמנטים
סטטיים, **לא למה שמתרנדר ב-`innerHTML`**.

### 3. טבלת המהלכים — החלק העיקרי

מתחת למשבצות, ממוינת לפי `impact × speed` (fast=3, medium=2, heavy=1).

| עמודה | תוכן |
|---|---|
| # | סדר |
| סוג | תג צבעוני: `S×O` לדחוף · `W×O` לתקן כדי לנצל · `S×T` להגן · `W×T` קו אדום |
| מה עושים | משפט הפעולה |
| על סמך מה | שני הפריטים, כטקסט מקוצר עם טולטיפ מלא |
| השפעה | 1-3 נקודות |
| מהירות | מהיר / בינוני / כבד |
| ✔ | צ'קבוקס "בוצע" |

**`W×T` הוא המקום היחיד שבו מותר אדום** — רקע אדום בהיר וגבול אדום.
`אדום שמור להתרעות בלבד` הוא כלל, לא הצעה.

**כל `W×T` מוצג תמיד**, גם אם הניקוד שלו נמוך, וגם אם המשתמש סינן.

מעל הטבלה: משפט אחד שמסביר את הסדר —
*"הסדר הוא סדר טיפול (השפעה × מהירות ביצוע), לא תחזית הצלחה."*

### 4. לשונית "מה זז" — רק בריצה חוזרת

מוצגת רק אם `DATA.previous` קיים. ארבעה בלוקים:

- **נוסף** — פריטים חדשים, לפי משבצת
- **נעלם** — פריטים שהיו ואינם. *"חולשה שנעלמה — מה שינית?"*
- **התחזק / נחלש** — שינוי `strength`
- **מהלכים שסומנו בוצעו** ומה קרה למשבצות שהם נגעו בהן

**אם מהלך סומן בוצע ואף פריט לא זז — הלוח אומר את זה במפורש.** זו התובנה
הכי שווה שהכלי מייצר, ולא מרככים אותה.

### 5. פאנל הגדרות מתקפל

**מקופל כברירת מחדל.** בתוכו: סינון לפי סוג מהלך · הצגה/הסתרה של התרשמויות
(`kind: impression`) · כפתור "אפס סימוני בוצע" · כפתור הדפסה.

## התנהגות

- **שמירה אוטומטית ל-localStorage** — סימוני `done`, מצב הפאנל, והסינון.
  מפתח: `swot-board:<business>`. כל קריאה וכתיבה ב-`try/catch` — דפדפן שחוסם
  אחסון לא שובר את הלוח.
- **חסר מוצג "חסר", לא אפס.** משבצת ריקה כותבת *"לא נמצאו פריטים — ראה שורת
  הכיסוי"*, לא `0`.
- **עובד בטלפון** — טור אחד, טבלת המהלכים גוללת אופקית בתוך `overflow-x: auto`
  משלה. הדף עצמו לא נגלל לרוחב.
- **הדפסה** — `@media print`: הפאנל והצ'קבוקסים נעלמים, המשבצות והטבלה נשארות
  על עמוד אחד או שניים.

## אחרי הבנייה

פתח את הקובץ בדפדפן (או הנחה את המשתמש), ועברו יחד על **המהלך הראשון בטבלה**.
אם המשתמש אומר "זה לא רלוונטי" — זה סימן שפריט במשבצת לא מדויק. **חזור למשבצת,
תקן, ובנה מחדש.** לוח שהמהלך הראשון בו לא מדבר אל המשתמש הוא לוח שלא נגמר.
